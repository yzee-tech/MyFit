# The CI shards: one line each, the test files that shard runs (filters on the file path; a test file that
# matches any of a line's filters is run by that shard). Every test must be in exactly one shard:
# shards.sh check fails otherwise. Playwright's own --shard splits by test count, which put all the fast
# logic tests in one shard and the slow browser tests in the other (1 minute against 8), so the slow
# browser files (tests/models) are split by file name instead, at the letter that balances their time.
# The shard durations are in each run's job summary: move the letter if they drift apart.
